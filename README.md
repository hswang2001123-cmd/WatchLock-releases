# Watch Lock

一个住在菜单栏里的 Mac 小工具：一键锁屏熄屏，回来抬手用 Apple Watch 解锁；顺手管好截图、文件、剪贴板和拥挤的菜单栏。

**[⬇ 下载最新版](../../releases/latest)** · 需要 macOS 13 或更新版本 · 免费试用 3 天

---

## 功能

### 🔒 一键锁屏，Apple Watch 解锁
按下自定义快捷键，立即锁定并关闭显示器。回来按任意键，戴着已解锁的 Apple Watch 就会自动解锁。推荐把机械键盘的闲置键映射成 F13–F20 专门用来锁屏。不读取、不保存密码，也不需要辅助功能权限。

### 👕 晾衣绳
屏幕顶部、菜单栏下面的一条晾衣绳，截图、图片、文件和文件夹都能夹上去。
- **截图自动挂上**：照常按 ⇧⌘3 / ⇧⌘4，截图会从截取的位置飞到绳上，不再堆满桌面。
- **拖上去就挂**：把文件或文件夹拖到屏幕顶部，绳子落下接住，松手即挂。文件留在原处。
- **用的时候拉下来**：鼠标在菜单栏停一下，整条绳子滑下来；移开就收起。
- 单击复制、双击打开、长按快速查看；拖进文件夹是移过去，拖进 App 是拷贝，拖到废纸篓就删除。
- 卡片会随风轻轻摆动，挂上时晃几下，取下时翻着掉落。

### 📋 剪贴板历史
记住最近 30 条复制过的文字、图片和文件，在菜单里点一下就放回剪贴板。菜单打开时可直接按 1–9 选取。密码管理器复制的密码不会被记录。

### ↔️ 菜单栏图标折叠
刘海屏 MacBook 的菜单栏图标太多会被挡住。按住 ⌘ 把不常用的图标拖到分隔点左边，点箭头就能收起；展开后会自动收回。

### 🖥 屏幕与连接
- 查看外接显示器，单独熄灭或唤醒某一块屏幕（需显示器支持 DDC/CI）。
- 试用并切换 HiDPI 等分辨率，20 秒内不确认会自动恢复。
- 查看 USB-C 线缆的速度、供电能力和充电器协商功率（Apple 芯片、macOS 14 及以上）。

### 📄 新建 TXT
在 Finder 当前打开的文件夹里直接新建文本文件，包括 OneDrive、iCloud 这类云盘文件夹。也可以在 Finder 里右键使用。

## 安装

1. 在 [Releases](../../releases/latest) 下载 `Watch-Lock-版本号.dmg`。
2. 打开后把 **Watch Lock** 拖进“应用程序”。
3. 第一次打开时如果提示“无法验证开发者”或“已损坏”：打开“系统设置 → 隐私与安全性”，在页面下方点“仍要打开”。也可以在终端运行：
   ```
   xattr -dr com.apple.quarantine "/Applications/Watch Lock.app"
   ```
4. 点菜单栏的锁图标开始使用。之后的新版本会在 App 内自动提示更新。

## 试用与购买

- 首次打开起免费试用 **3 天**，期间所有功能都能用。
- 试用结束后，锁屏和关闭显示器仍可免费使用；晾衣绳、剪贴板历史、菜单栏图标折叠、屏幕与连接、新建 TXT 需要激活码。
- 一个激活码可在 **2 台 Mac** 上使用。激活时联网登记一次，之后每周静默核对一次，断网也不影响使用。换电脑前可在激活窗口里“移除本机激活”，把名额让出来。
- 购买 / 支持作者：[爱发电主页](https://afdian.com/a/hswang2001)

## 隐私

Watch Lock 不收集数据，不上传任何内容。剪贴板历史和晾衣绳的记录只保存在你自己的 Mac 上。联网只有两处：每天检查一次是否有新版本；激活码登记设备时发送激活码和一串匿名的设备编号（硬件 ID 的哈希值，无法反推出你的电脑信息）。
